# margem

Esqueleto inicial: Next.js (App Router) + TypeScript + Tailwind CSS v4.

## Rodar em desenvolvimento

```bash
npm install
npm run dev
```

Abre em [http://localhost:3000](http://localhost:3000).

## Estrutura

```
app/             # rotas e páginas (App Router)
components/      # componentes de UI (vazio por enquanto)
lib/engine/      # motor de cálculo (futuro)
lib/ai/          # integração de IA (futuro)
```

Supabase e IA ainda não foram adicionados — este é apenas o esqueleto que roda.
